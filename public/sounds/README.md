# Interface sounds

`interface-select.wav` is Old School RuneScape's interface button sound, `interface_select1`
(sound ID 2266 in the game cache; see the OSRS Wiki's
[List of sound IDs](https://oldschool.runescape.wiki/w/List_of_sound_IDs)). The file is from
[SoaresPT/OSRS-SoundEffects-Dumps](https://github.com/SoaresPT/OSRS-SoundEffects-Dumps)
(`sounds/2266.wav`), a dump of the game cache, unchanged: 8-bit mono PCM at 22,050 Hz, 125 ms.

The sound belongs to Jagex Limited and is used under the terms of Jagex's Fan Content Policy, like
the traced sprites. It is played by the docs site only (site/sound.ts) and is not part of the
registry.
