<Component path="sprites/demo" />

## Installation

```bash
npx shadcn@latest add {{registry}}/prayer-sprites.json
```

## Usage

```tsx
import { prayerSprites, PietyPrayer } from "@/components/ui/prayer-sprites"

<PietyPrayer scale={2} />
{Object.entries(prayerSprites).map(([name, Sprite]) => <Sprite key={name} />)}
```
