## Installation

```bash
npx shadcn@latest add {{registry}}/slider.json
```

## Usage

```tsx
<Slider defaultValue={70} />
```

## Options

| Prop | Default | Description |
| --- | --- | --- |
| `thumb` | `"blue"` | Jewel colour: `blue`, `green`, `red`, `gray`. |
| `notches` | `5` | Number of notch dots drawn on the bar. |
