## Installation

```bash
npx shadcn@latest add {{registry}}/dropdown-menu.json
```

## Usage

The game uses it for the hamburger menu that switches a window's view (Bank, Collection Log, Combat Achievements). Inside a window header, [`WindowMenu`](/components/window) wires this up for you.

```tsx
<DropdownMenu>
  <DropdownMenuTrigger aria-label="Menu">…</DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuRadioGroup value={view} onValueChange={setView}>
      <DropdownMenuRadioItem value="overview">Overview</DropdownMenuRadioItem>
      <DropdownMenuRadioItem value="tasks">Tasks</DropdownMenuRadioItem>
    </DropdownMenuRadioGroup>
  </DropdownMenuContent>
</DropdownMenu>
```

Use `DropdownMenuItem` for plain actions and `DropdownMenuSeparator` between groups. For the right-click "Choose Option" menu, use [Context Menu](/components/context-menu).
