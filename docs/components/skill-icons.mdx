## Installation

```bash
npx shadcn@latest add {{registry}}/skill-icons.json
```

## Usage

```tsx
import { AttackIcon, SkillIcon } from "@/components/ui/skill-icons"

<AttackIcon />            {/* follows --osrs-px */}
<AttackIcon scale={4} />  {/* 100 × 100 */}
<SkillIcon skill="sailing" size={50} />
```

## Notes

Icons are 25×25 and stay sharp at whole-number scales. Download them as SVG or PNG on the [Assets](/assets) page.
