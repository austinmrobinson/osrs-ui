<Component path="settings/demo" />

## Installation

```bash
npx shadcn@latest add {{registry}}/settings.json
```

## Usage

```tsx
<SettingsSection title="Combat">
  <SettingRow label="Hitsplat tinting"><Checkbox /></SettingRow>
</SettingsSection>
```

## Descriptions and stacked rows

```tsx
<SettingRow label="Hide roofs" description="When enabled, hides all roofs.">
  <Checkbox variant="bordered" />
</SettingRow>
<SettingRow layout="stacked" label="Screen Brightness" description="Change the level of brightness…">
  <Slider defaultValue={40} />
</SettingRow>
```
