<Component path="number-field/playground" />

## Installation

```bash
npx shadcn@latest add {{registry}}/number-field.json
```

## Usage

```tsx
<NumberField defaultValue={1000} min={1} />
```

`variant="inset"` puts − / + buttons inside the field, drawn like a [Select](/components/select)'s arrow button, for settings rows and side panels.

```tsx
<NumberField variant="inset" defaultValue={0} min={0} />
```
