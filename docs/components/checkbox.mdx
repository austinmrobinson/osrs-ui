<Component path="checkbox/playground" />

## Installation

```bash
npx shadcn@latest add {{registry}}/checkbox.json
```

## Usage

```tsx
import { Checkbox } from "@/components/ui/checkbox"

<Checkbox defaultChecked />
```

## Notes

`checked="indeterminate"` shows the crossed box.

## Variants

`variant="bordered"` is the larger tan-bordered box from the modern Settings window.

```tsx
<Checkbox variant="bordered" defaultChecked />
```
