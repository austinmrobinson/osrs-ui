OSRS UI recreates the Old School RuneScape interface as a [shadcn/ui](https://ui.shadcn.com) registry. Every frame, texture and icon is a **vector SVG traced pixel for pixel from the game's sprites**. They stay sharp at any integer scale, and a check in CI confirms they still match the original pixels exactly.

<Component path="interface/demo" />

## What's different

- **Vector, not screenshots.** Each sprite is converted to merged SVG rectangles, one path per colour, with no smoothing or tracing guesswork.
- **Frames that resize.** Buttons, interfaces and tabs are 9-slice and 3-slice frames that repeat the game's own edge sprites, so they work at any width or height.
- **One scale knob.** `--osrs-px` is the size of one game pixel. Set it to `1px`, `2px`, `3px` and so on; every frame, font and gap follows.
- **Free downloads.** Every icon and frame can be downloaded as SVG or PNG at any size on the [Assets](/assets) page, which is handy for video thumbnails and overlays.
