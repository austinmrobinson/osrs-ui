OSRS UI recreates the Old School RuneScape interface as a [shadcn/ui](https://ui.shadcn.com) registry. Every frame, texture and icon is a **vector SVG traced pixel for pixel from the game's sprites**. They stay sharp at any integer scale, and a check in CI confirms they still match the original pixels exactly.

## What's different

<IconList>
  <IconListItem icon="vector" title="Vector, not screenshots" label="Traced">every sprite pixel for pixel into merged SVG rectangles, one path per colour</IconListItem>
  <IconListItem icon="frames" title="Frames that resize" label="Fits">any width or height: buttons, windows and tabs repeat the game's own edge sprites</IconListItem>
  <IconListItem icon="scale" title="One scale knob" label="Set">`--osrs-px` to 1px, 2px or 3px and every frame, font and gap follows</IconListItem>
  <IconListItem icon="downloads" title="Free downloads" label="Formats">SVG or PNG at any size from the [Assets](/assets) page, for thumbnails and overlays</IconListItem>
</IconList>
